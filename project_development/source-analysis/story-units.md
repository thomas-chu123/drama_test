# 劇情單元（本批覆蓋 sequence 1–3）

## 故事框架
目前三段呈現「偶發救援任務」與多線群像武俠的開端：段譽因不忍旁觀，承諾救鍾靈，逐步被江湖門派、身世線索與木婉清的追捕線捲入。全書框架與後續人物線交會尚未拆解，以下只概括本批。

## U01｜七日內救回鍾靈
- **章節範圍**：sequence 1–3（原文章 1–3）
- **開場局面**：段譽在無量劍比劍會場只是旁觀者；鍾靈介入保他，神農幫隨後扣住鍾靈。
- **核心衝突**：段譽無武功，卻要在七日毒發前救鍾靈；他必須借助陌生人與新得的武學自保，但不願把能力用於傷人。
- **付出代價**：段譽服下斷腸散、錯失時間、失去金盒並反覆受傷；鍾靈一度獲救，但閃電貂毒是否解除未明。
- **結束局面**：段譽、木婉清與鍾靈短暫脫離神農幫控制，但木婉清的追兵再次包圍，救援任務的危機尚未完全落定。
