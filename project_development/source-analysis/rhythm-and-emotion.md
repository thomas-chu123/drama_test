# 節奏與情緒（本批覆蓋 sequence 1–3）

## 懸念推進
1. 段譽為何在武林衝突中堅持不出手？（seq 1）
2. 鍾靈被扣、段譽中毒，能否在七日內帶回救援？（seq 1）
3. 絕谷中的玉壁影像究竟是什麼，段譽能否脫困？（seq 2）
4. 鍾家為何寫下「姓段者入谷殺無赦」，金盒中的生辰紙片又指向誰？（seq 2–3）
5. 木婉清為何遭人追捕，段譽會否繼續留下救她？（seq 3）
6. 假扮靈鷲宮使者救出鍾靈後，司空玄與追兵會否識破或追上？（seq 3）

## 情緒起伏
- **憋屈轉喜劇**：段譽不會武功，被龔光傑掌摑仍拒絕鬥武；鍾靈以毒物反制。（seq 1）
- **危機加壓**：屍體上的毒字引出神農幫衝突，段譽被下七日毒藥。（seq 1）
- **絕境奇觀與獲得**：墜谷、看破玉壁影像、進入石洞取得卷軸。（seq 2）
- **情義拉扯**：段譽明知自己可能受害仍去萬劫谷報信、回頭警告木婉清。（seq 2–3）
- **局部解氣後再遇險**：假身份迫使司空玄放人，隨即木婉清被追兵堵截。（seq 3）
