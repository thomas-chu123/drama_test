# ch-3 馬疾香幽

- 原文：input/dragon_cht.txt
- 索引行號：423–626（sequence 3；原文章號 3）

## 概要
鍾夫人讓段譽借黑玫瑰趕赴大理求援，段譽途中聽見伏擊者要對付馬主，折返示警，卻因此被捲入木婉清遭追捕的衝突。段譽雖身無武功，仍屢次為保護木婉清而冒險；木婉清一面出手救他，一面因面幕與男性的不信任保持戒備，兩人關係由互相嫌棄轉成同行。兩人以靈鷲宮聖使的身份唬住神農幫，段譽救出鍾靈並取得斷腸散解藥，但木婉清給司空玄的香粉未必真能解貂毒。救援剛成功，木婉清被原先的追兵堵截，段譽再次拒絕丟下救過自己的同伴，兩人負傷突圍後仍遭追兵圍逼。

P6 轉折 | 木婉清追問生辰紙片後認為段譽欺騙她；原先追兵從前後包圍，鍾靈離開，段譽選擇留下助木婉清 | 涉及：段譽、木婉清、鍾靈、瑞婆婆、平婆婆 | 功能：救援成功帶來的新危機反而切斷撤退路線；段譽再次以守信和不棄同伴作選擇（行 606–626）

## 出場人物
- 段譽：受毒期限驅使赴救援，拒絕棄下木婉清。
- 木婉清：戴面幕、使用毒箭與黑玫瑰的少女，被追兵追捕。
- 鍾靈：神農幫人質，獲救後仍記掛閃電貂及段譽承諾。
- 司空玄：神農幫主，誤把段譽、木婉清當作靈鷲宮聖使。
- 瑞婆婆、平婆婆及其他靈鷲宮使者：追捕木婉清的一方。
- 干光豪、葛光佩：在米店出現並企圖殺段譽滅口。
