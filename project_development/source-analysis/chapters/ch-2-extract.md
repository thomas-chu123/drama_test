# ch-2 玉壁月華明

## 概要
段譽離開劍湖宮後，在溪邊聽見無量劍東西宗弟子干光豪、葛光佩私奔，遭追逐時失足墜入深谷。谷中無路可出，他從月光投影看破「無量玉壁仙影」並找到石洞，接觸逍遙派遺留的北冥神功與凌波微步卷軸；他雖按卷軸習得武學，仍把逃走視為首選，並未改變不喜鬥武的心性。段譽終於找到谷外通道，循鍾靈所述路徑抵達萬劫谷，向鍾夫人報告女兒被扣的消息。鍾夫人因丈夫鍾萬仇與四大惡人來客牽制，無法立刻同行，將金盒和求助段正淳的口信交給段譽，使救援再添身世與舊情疑問。

- 鍾夫人（本章稱鍾夫人，後文揭姓名甘寶寶）：鍾靈之母，交付金盒與口信。
